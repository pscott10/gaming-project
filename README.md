# Gaming Project
This repository is for the senior project created by Ally Robinson and Paige Scott. This web application will aid owners of gaming establishments in Illinois to create comprehensive revenue reports to support their business decisions.

# Project Structure
Project structure description of each file/folder:

### Frontend
 - frontend/ - Contains the React app for the user interface
 - frontend/package.json - Manages frontend dependencies and scripts
 - frontend/src/ - Contains React components and application logic

 ### Backend
 - backend/ - contains the server-side logic for handling database requests and API endpoints
 - backend/controllers/ - manages the logic to handle requests for data
 - backend/models/ - contains database schema and logic for interacting with the database
 - backend/routes/ - defines the API routes for the server

 ### Database
 - database/ - contains scripts for setting up and managing the database
 
 ### Setup for the project
 - Clone the repository
 - Navigate the the frontend folder and run npm install to install frontend dependencies
 - Run npm run dev to start the dev server
